- **Identity**: `webdep` v2.0.0 (`Cargo.toml`; `package.json` legacy `nexus-deploy` v2.0.0). `APPLICATION` — single-binary PaaS, Git deployer, process supervisor, native PostgreSQL cluster manager, embedded Vanilla ES6 SPA.
- **Languages/Stack**: Rust 2021 (`tokio` 1 `worker_threads=2`, `axum` 0.7, `tower`/`tower-http` gzip, `rusqlite` 0.32 WAL `schema_version=3`, `argon2` 0.5, `aes-gcm` 0.10, `sysinfo` 0.32, `rust-embed` 8.5, `tracing`); Vanilla ES6 JS/HTML/CSS + `@speed-highlight/core` 2.1.0; `start.{sh,ps1,bat}`.
- **Entry**: `src/main.rs:40` `main()`; frontend `public/index.html` → `public/app.js`.
- **Dirs**: `src/{api/{projects,system},auth,databases,deployer,projects,runtime}`, `public/{css,js,vendor}`, `tests/rust_e2e.rs`, `docs/images`, `tools/` (empty). Skip: `data/`, `saved data/`, `target/`, `node_modules/`.
- **Bootstrap (`src/main.rs`)**: Linux `mallopt` (`M_ARENA_MAX=2`, `M_TRIM_THRESHOLD=64KB`) → `tracing_subscriber` → `Config::from_env` (writes default `.env` if missing) → `open_db` → `Vault` (`master.key`) → `Auth` (syncs Main Admin `id=1`, spawns UTC sync) → `Projects` → `Logs` (`broadcast(2048)`) → `Monitor` (sampler) → `AppCache` → `Caddy` → `Runtime` (2s supervisor) → `Deployer` (`Semaphore(1)`) → `Databases` → `Updater`. Spawns: 60s maintenance (prune cache/sessions/auth maps, cap `logs` 20k rows, `shrink_memory`, `malloc_trim`); startup workload resume/orphan cleanup; 2s `target/release/webdep(.exe)` hot-reload watcher (`WEBDEP_RESTARTED=1`). Binds `HOST:PORT` (60×500ms retry) → `axum::serve`. No `ctrl_c` shutdown hook.
- **Auth/RBAC (`src/auth/`, `src/api/common.rs`)**: `nd_session` cookie (`HttpOnly; SameSite=Strict`) + `X-CSRF-Token` on mutations. Argon2id + 5-fail/10m lockout (`3` for 2FA) + RFC 6238 TOTP/backup codes + P-256 WebAuthn passkeys. `id=1`/`admin` = Main Admin (`*`); sub-users scoped by `allowed_projects` + granular powers.
- **Toolchain & Doc Diff**: `cargo build --release`, `cargo test`, `cargo check`, `node --check public/app.js`. No CI/Dockerfile. `README.md` claims `RUST_LOG` default `webdep=info`; `src/main.rs:53` defaults `webdep=info,tower_http=info`.
