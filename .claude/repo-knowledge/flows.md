# WebDep — Execution Flows

1. **Auth & Request Guard**: `POST /api/auth/login` (`src/api/auth.rs:23`) → `Auth::check_lockout` (5 fails/10m) → Argon2 `verify_password` → if `totp_enabled`: 3m `mfa_challenges` token → `POST /api/auth/2fa/verify-login` (or `passkeys/login/finish` P-256 ECDSA) → `create_authenticated_response` sets `nd_session` cookie + `csrf` token. Every protected `/api/*` passes `security_middleware` (`src/api/common.rs:40`): verifies session (30s cache→SQLite), checks `X-CSRF-Token` on mutations (except logout), handler checks `verify_power`/`verify_main_admin`, mutation invalidates `AppCache`.

2. **7-Stage Git Deploy & Rollback**: `POST /api/projects/:id/deploy` or `POST /api/webhooks/github/:slug` (HMAC-SHA256) → `Deployer::create_deployment` → `tokio::spawn` `run_deploy` (`src/deployer/worker.rs:12`): `Semaphore(1)` FIFO permit → `ensure_container` → `fetching` (`Git::clone_or_fetch`/`resolve_head`) → `pulling` (`Git::checkout` to `releases/rel-<id>`) → `installing` (`install_cmd`) → `building` (`build_cmd`) → `deploying` (`switch_current` + `Runtime::start_project`, aborts if `stop_seq` changed) → `health_checking` (HTTP/TCP + `stability_s`) → updates `projects`/`deployments`/`AppCache`. `run_rollback` (`worker.rs:293`) acquires `Semaphore(1)` → `switch_current` → restart + health check.

3. **Process Lifecycle & Supervisor**: `Runtime::start_project` (`src/runtime/process.rs:13`) acquires per-project mutex → stops maintenance server → `kill_pid_tree` old PID/port → injects Vault-decrypted `project_env` + `PORT` + `APP_URL` → spawns `sh`/`cmd`, streams stdout/stderr to `Logs::add(..., "app", ...)`. `start_background_monitor` (`src/runtime/supervisor.rs:11`) checks child `try_wait()` every 2s (preserved PIDs every 6s), marks exited workloads `'stopped'`.

4. **Telemetry & Live Log SSE**: `public/app.js:30` `pollTick` polls every 4.5s (visible tab, editor closed) via `api.js` SWR cache; `Monitor` samples host/process `sysinfo` stats. `EventSource('/api/logs/stream?project=id')` (`src/api/logs.rs:74`) sends SQLite backlog then streams `Logs::subscribe()` broadcast entries (`channel=="app"`).

5. **Managed PostgreSQL & Linking**: `POST /api/databases` (`src/api/databases.rs:95`) → `Databases::create` allocates port (`allocate_global_unique_port`), runs `initdb` + writes `pg_hba.conf`/`postgresql.conf`, starts `pg_ctl`, creates user/db via `psql`, syncs `ufw`. `POST /api/databases/:id/link` writes encrypted `DATABASE_URL` into `project_env`.
